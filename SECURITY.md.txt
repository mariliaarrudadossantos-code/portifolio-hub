# Políticas de Segurança

## Autenticação
- Autenticação de dois fatores (2FA) ativada via aplicativo autenticador
- Acesso ao repositório protegido por senha forte

## Proteção de Branch
- A branch principal está protegida contra alterações diretas
- Todas as alterações devem passar por revisão antes do merge

## Boas Práticas Adotadas
- Commits com mensagens descritivas
- Repositório público somente para visualização
- Nenhuma senha ou dado sensível armazenado no repositório

## Ferramentas Utilizadas
- Git para versionamento local
- GitHub para hospedagem e controle de acesso
- Google Gemini como apoio na implementação das práticas de segurança
