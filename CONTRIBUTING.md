# Guia de Contribuição — Portfólio Hub

## Sobre o Projeto
Este repositório foi desenvolvido como parte da disciplina de Engenharia de Software,
utilizando Git, GitHub e Google Gemini como ferramentas de apoio.

## Como Contribuir
1. Faça um fork do repositório
2. Crie uma branch para sua feature: git checkout -b minha-feature
3. Faça suas alterações e commit: git commit -m "descrição da alteração"
4. Envie para o GitHub: git push origin minha-feature
5. Abra um Pull Request para revisão

## Padrão de Commits
- feat: nova funcionalidade
- fix: correção de bug
- docs: atualização de documentação
- style: alterações visuais

## Ferramentas Utilizadas
- Git e GitHub para versionamento
- Google Gemini como apoio na implementação
- GitHub Pages para publicação do site
